You download and run the EXE yourself. The add-in has not been published in Microsoft Marketplace.

Before installing

  1. Local connections require Hermes already installed on your computer. Remote connections require a reachable HTTPS Hermes server and the appropriate permissions.
  2. Run the installer, choose a local or remote connection, and follow its instructions.
  3. Test on a new, empty workbook. Writes change the file, are not transactional, and must not be blindly repeated after an unknown outcome.

Beta status

On LTSC 2024, the add-in button may disappear after restarting Excel. Persistent ribbon access is unresolved. This build is not a store-ready release.

Handoff from a future store-installed pane to the local component is still being developed. This website does not detect or launch programs on your computer.

Network requirements

Your selected Hermes, its model provider, and Microsoft Office.js must be reachable at the same time. Locally hosted pane files do not make the add-in fully offline. See setup and limitations and data handling.
