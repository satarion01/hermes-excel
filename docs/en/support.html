HELP AND FEEDBACK

Support

Hermes Excel is a technical beta for Windows and desktop Excel. This is the project’s support page, not a repository link in place of documentation.

Installation

  1. Download the EXE from the home page. The checksum is included in the corresponding GitHub Release.
  2. You need an existing Hermes runtime. The installer does not include a separate model or second agent.
  3. Select local Hermes on this computer or a remote HTTPS address provided by the server owner. Do not publish credentials.
  4. Open the installer’s test workbook. Try chat and writes in a disposable file.

Known limitations

  • Persistent button visibility after restarting Excel on LTSC 2024 is unresolved. Registration alone does not guarantee a visible ribbon button.
  • Marketplace installation, a clean-machine scenario, macOS, and Excel on the web have not passed acceptance testing.
  • Remote Hermes requires compatible integration. Successful sign-in does not grant permission to install a server plugin.
  • Office.js and the model provider need network access. Your VPN or proxy must allow all required connections simultaneously.
  • Comments and threads are unsupported on tested Office builds; Power Query support is metadata-only.
  • After an unknown write outcome, inspect the workbook’s actual state before attempting another write.

Report a problem

Open an issue

Include Windows and Excel versions, installer version, local or remote mode, and the exact error. Do not attach working files, tokens, passwords, private server addresses, or logs containing personal data. All GitHub Issues are public.
