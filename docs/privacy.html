Конфиденциальность

Эта страница описывает публичный сайт и текущую техническую бету Hermes Excel. Она не заменяет правила вашего Hermes, выбранного поставщика модели или Microsoft.

Публичный сайт и загрузки

Сайт размещён на GitHub Pages, файлы распространяются через GitHub Releases. Мы не добавляем на эти страницы аналитику, рекламные трекеры, формы входа или собственные cookies. GitHub может обрабатывать IP-адрес, технические сведения о запросах и другие данные по своей политике конфиденциальности. Ваш выбор языка сохраняется в хранилище браузера, если оно доступно. Сам сайт не читает книги Excel и не подключается к локальному helper.

Панель Excel

Выбранный Hermes получает сообщения чата и данные, необходимые для разрешённых операций. Контекст выделения отправляется при явном прикреплении к сообщению. При активном доступе к книге агент может запрашивать ограниченные диапазоны и выполнять поддержанные чтение/запись; результаты и разницы возвращаются через интеграцию.

Адреса подключений и настройки интерфейса могут сохраняться локально. Несекретные настройки привязки диалога могут сохраняться внутри книги. Ключи поставщика модели остаются у соответствующего развёртывания Hermes; страница сайта их не запрашивает.

Панель загружает Office.js с инфраструктуры Microsoft. В удалённом режиме данные передаются выбранному серверу; даже локальный Hermes может обращаться к внешнему поставщику модели. Поэтому мы не обещаем, что данные не покидают компьютер.

Хранение и дальнейшая обработка

История чата, журналы и данные, поступившие Hermes и его поставщику модели, обрабатываются согласно настройкам и правилам этих сервисов. Эта надстройка не определяет их сроки хранения, использование для обучения или процедуры удаления. Для таких вопросов обращайтесь к владельцу выбранного Hermes и поставщику модели. Не передавайте конфиденциальные книги без соответствующего разрешения.
