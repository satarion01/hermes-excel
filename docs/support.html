Поддержка

Hermes Excel — техническая бета для Windows и настольного Excel. Это страница поддержки проекта, а не ссылка на исходный репозиторий вместо документации.

Установка

  1. Скачайте EXE на главной странице; контрольная сумма находится в описании соответствующего GitHub Release.
  2. Нужен существующий Hermes. Установщик не содержит отдельную модель или второй агент.
  3. Выберите локальное подключение к Hermes на компьютере либо удалённый HTTPS-адрес, выданный владельцем сервера. Учётные данные не публикуйте.
  4. Откройте предложенную установщиком тестовую книгу. Проверяйте чат и запись на одноразовом файле.

Известные ограничения

  • Закрепление кнопки после нового запуска Excel на LTSC 2024 пока не решено. Регистрация надстройки сама по себе не гарантирует видимую кнопку.
  • Магазинная установка, чистая машина, macOS и Excel в браузере ещё не приняты тестированием.
  • Удалённому Hermes нужна совместимая интеграция. Успешный вход не означает права на установку серверного плагина.
  • Office.js и поставщик модели требуют сетевого доступа. VPN/прокси должны пропускать все нужные подключения одновременно.
  • Комментарии/обсуждения на проверенных Office не поддержаны; Power Query — только метаданные.
  • После неизвестного результата записи не отправляйте её повторно: сначала сверяйте фактическое состояние книги.
